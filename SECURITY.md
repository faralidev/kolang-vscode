# Security Policy / سیاست امنیتی

## Reporting a vulnerability / گزارش آسیب‌پذیری

Please **do not** open a public GitHub issue for security vulnerabilities.

لطفاً برای گزارش آسیب‌پذیری‌های امنیتی، issue عمومی نسازید.

Instead, report vulnerabilities privately:

1. Go to <https://github.com/faralidev/kolang-vscode/security/advisories/new>.
2. Click **"Report a vulnerability"**.
3. Provide a description, affected versions, reproduction steps, and impact.

You should receive a response within 72 hours.

## Scope / دامنه

This policy covers the `kolang-vscode` VS Code extension. For the
`kolang-linter` binary, the `kolang` interpreter, or `kolang-ide`, see their
own repositories.

## Supported versions / نسخه‌های پشتیبانی‌شده

| Version | Supported |
|---------|-----------|
| 0.2.x   | ✅         |
| < 0.2   | ❌         |
